# ⚡ JinX Panel — 3x-ui One-Click Railway Deploy

پنل مدیریت Xray مبتنی بر [3x-ui](https://github.com/MHSanaei/3x-ui) با قابلیت **دیپلوی یک‌کلیکی روی Railway** —
از لحظه‌ای که دیپلوی تموم می‌شه، یک اینباند **VLESS + WebSocket + TLS** به اسم
`جینکس | Super JinX` به‌صورت خودکار ساخته می‌شه و ساب‌لینکش هم بدون هیچ دست‌کاری آماده‌ست.

## ✨ امکانات

- 🚀 **صفر تنظیمات دستی** — بعد از دیپلوی، اینباند خودش ساخته می‌شه
- 🔁 **مقاوم در برابر ریستارت** — اگه اینباند حذف بشه، با هر ریستارت دوباره ساخته می‌شه
- 🔐 امنیت TLS در لبه‌ی شبکه‌ی Railway (بدون نیاز به گواهی دستی)
- 📡 ساب‌لینک آماده، بدون نیاز به تنظیم اضافه

## 🚀 دیپلوی روی Railway

1. این ریپو رو فورک/کلون کن.
2. توی Railway یک پروژه جدید از روی این ریپو بساز (Deploy from GitHub repo).
3. تو تب Variables این‌ها رو ست کن (اختیاری، پیش‌فرض هم کار می‌کنه):
   - `XUI_USERNAME`
   - `XUI_PASSWORD`
   - `INBOUND_UUID` (اگه خالی بمونه، خودش یک UUID تصادفی می‌سازه)
4. دیپلوی بزن. بعد از بالا اومدن، وارد پنل شو (`https://<your-app>.up.railway.app`) و از قسمت Inbounds
   اینباند `جینکس | Super JinX` رو می‌بینی — از همون‌جا هم QR و هم ساب‌لینک در دسترسه.

## 📁 ساختار پروژه

```
.
├── Dockerfile
├── railway.toml
└── scripts/
    ├── entrypoint-wrapper.sh   # اجرای پنل + راه‌اندازی خودکار
    ├── setup-inbound.sh        # ساخت اینباند از طریق API پنل
    └── protect-inbound.js      # (اختیاری) مخفی‌کردن دکمه‌ی حذف در UI
```

## ⚠️ نکات مهم

- چون این پروژه بر پایه‌ی ایمیج رسمی 3x-ui ساخته شده، هر آپدیتی که نویسنده‌ی اصلی روی ساختار API یا
  رابط کاربری بده ممکنه نیاز به هماهنگ‌سازی اسکریپت‌های `scripts/` داشته باشه.
- Railway فقط یک پورت عمومی به هر سرویس می‌ده؛ به همین خاطر پنل و اینباند وب‌سوکت هر دو روی همون
  پورت (پیش‌فرض `8080`) کار می‌کنن.
- رمز پیش‌فرض پنل رو حتماً از تب Variables عوض کن.
